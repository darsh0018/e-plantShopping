
# Paradise Nursery Shopping Application

## Project Description

Paradise Nursery is a React-based online plant shopping application where users can browse indoor plants, view product prices, add plants to a shopping cart, update quantities, and remove products.

## Features

- Landing page with the Paradise Nursery name and Get Started button
- Plant listings grouped into three categories
- Product images, descriptions, and prices
- Add to Cart functionality
- Shopping cart with quantity controls and item removal
- Automatic calculation of item subtotals and total cart amount
- About Us section
- Responsive CSS styling

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- Redux Toolkit
- React Redux

## How to Run the Project

1. Install Node.js and npm.
2. Open a terminal in the project directory.
3. Install project dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

## Note

This application is an educational demonstration. Checkout is a demo feature and does not process real payments.
